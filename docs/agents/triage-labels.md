# Triage labels

Map each triage role to the same label in GitHub.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer must assess the issue |
| `needs-info` | `needs-info` | The reporter must add details |
| `ready-for-agent` | `ready-for-agent` | An agent can start the issue |
| `ready-for-human` | `ready-for-human` | A person must implement the issue |
| `wontfix` | `wontfix` | The team will not act on the issue |

When a skill names a role, use the matching GitHub label. Edit the second column if the repo changes its label names.
